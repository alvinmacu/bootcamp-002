S- 
• Amenaza: Spoofing
• Atributo de Seguridad Violado: Autenticidad
• ¿Qué intenta el atacante?: Lanzar peticiones GET como si fuera un usuario válido(mediante el robo de tokens de sesión, credenciales o llaves de API)
• Contramedidas / Mitigaciones Comunes: Autenticación fuerte mediante OAuth 2.0 / OpenID Connect (validando firma, emisor iss y expiración exp del JWT), uso obligatorio de HTTPS/TLS, y mTLS si el endpoint es consumido por microservicios internos.

T-
• Amenaza: Tampering
• Atributo de Seguridad Violado: Integridad
• ¿Qué intenta el atacante?: Inyectar datos maliciosos en el campo del parámetro {id}
• Contramedidas / Mitigaciones Comunes: Validación estricta del formato y tipo de dato en {id} (ej. entero positivo), uso de consultas parametrizadas/ORM en base de datos, y cifrado TLS en tránsito

R - Repudiation (Repudio)
• Amenaza: Repudiation
• Atributo de Seguridad Violado: No Repudio
• ¿Qué intenta el atacante?: Obtener información sensible de productos distintos valores en {id}
• Contramedidas / Mitigaciones Comunes: Logs de auditoría centralizados/inmutables para registrar el identificador del usuario/cliente con toda la traza(IP de origen, User-Agent y timestamp).

I-
• Amenaza: Information Disclosure
• Atributo de Seguridad Violado: Confidencialidad
• ¿Qué intenta el atacante?: Enviar un {id} con formato inválido para provocar errores no controlados que expongan stack traces con información sensible
• Contramedidas / Mitigaciones Comunes: Manejo de DTO's para devolver solo campos necesarios y sanitizar mensajes de error/cabeceras HTTP

D-
• Amenaza: Information Denial of Service
• Atributo de Seguridad Violado: Disponibilidad
• ¿Qué intenta el atacante?: Realizar ataques de miles de llamadas al servidor para bajarlo
• Contramedidas / Mitigaciones Comunes: Implementar Rate Limiting y cuotas por IP/cliente en el API Gateway, utilizar caché en memoria (Redis/CDN) tanto para respuestas exitosas (200) como para recursos no encontrados (404 con TTL corto), y aplicar autoescalado

E-
• Amenaza: Information Elevation of Privilege
• Atributo de Seguridad Violado: Autorización
• ¿Qué intenta el atacante?: Consultar información de productos a los que no tiene privilegio
• Contramedidas / Mitigaciones Comunes: Implementar control de acceso basado en roles o atributos (RBAC/ABAC) validando en el backend que el usuario autenticado tenga permisos específicos sobre el recurso {id} solicitado, y aplicar el principio de menor privilegio en los scopes del token.
